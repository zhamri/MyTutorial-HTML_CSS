## List

In CSS, the `color` property sets the text color, while the `background-color` property sets the background color of an
element.

## Ways to Define Colors in CSS

| **Format**      | **Example**                    | **Description**                                         |
|-----------------|--------------------------------|---------------------------------------------------------|
| **Named Color** | `color: blue;`                 | Uses a predefined color name (e.g., red, green, black). |
| **Hexadecimal** | `color: #ff0000;`              | Uses a 6-digit hex code for red (`#RRGGBB`).            |
| **Short Hex**   | `color: #f00;`                 | Shorthand for `#ff0000`.                                |
| **RGB**         | `color: rgb(255, 0, 0);`       | Red, Green, Blue values from 0–255.                     |
| **RGBA**        | `color: rgba(255, 0, 0, 0.5);` | Adds **alpha** for transparency (0–1).                  |
